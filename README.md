# Star Syria Browser (النجم السوري)

متصفح أندرويد خفيف مبني على WebView، بالمزايا التالية كنقطة انطلاق:

- محرك عرض ويب سريع خفيف على الرام (WebView وليس محرك متصفح كامل منفصل)
- حظر إعلانات أساسي عبر قائمة نطاقات (`assets/adblock_hosts.txt`) قابلة للتحديث
- درج (Drawer) لعرض التبويبات/الصفحات المفتوحة
- تنظيف الكاش وبيانات التصفح (كوكيز، تخزين، سجل) من شاشة الإعدادات
- تنزيل الملفات والفيديو عبر `DownloadManager` النظامي
- مشغل فيديو/ميديا مدمج (ExoPlayer عبر مكتبة Media3)
- اختيار محرك بحث افتراضي (Google / DuckDuckGo / Bing)
- رقم الإصدار ظاهر أسفل شاشة الإعدادات (`versionName` + `versionCode`)
- زر VPN يفتح تطبيق Proton VPN المثبت على الجهاز

## ملاحظة مهمة عن الـ VPN

بروتون (Proton VPN) لا يوفر SDK علني مجاني لدمج خدمته داخل تطبيقات أخرى — هذا
يتطلب اتفاقية شراكة رسمية معهم. لذلك الزر الحالي **يفتح تطبيق Proton VPN
الرسمي** إن كان مثبتاً (أو يوجّه لصفحته في المتجر إن لم يكن مثبتاً)، بدل
تشغيله داخلياً. لو أردت VPN مدمجاً بالكامل داخل التطبيق نفسه، الخيار الواقعي
هو بناء طبقة VPN عبر `VpnService` + بروتوكول WireGuard مفتوح المصدر مع
سيرفرات مجانية من مزود يوفر ذلك — وهذه مرحلة إضافية منفصلة يمكن بناؤها لاحقاً.

## البنية

```
StarSyriaBrowser/
├── app/
│   ├── build.gradle
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/starsyria/browser/
│       │   ├── MainActivity.kt        # الشاشة الرئيسية والمتصفح
│       │   ├── SettingsActivity.kt    # الإعدادات + رقم الإصدار
│       │   ├── VideoPlayerActivity.kt # مشغل الفيديو
│       │   ├── AdBlocker.kt           # فلترة الإعلانات
│       │   ├── BrowserTab.kt          # نموذج بيانات التبويب
│       │   └── TabViewHolder.kt       # عنصر عرض التبويب في الدرج
│       ├── res/                       # التخطيطات والألوان والنصوص
│       └── assets/adblock_hosts.txt   # قائمة حظر الإعلانات
├── build.gradle
└── settings.gradle
```

## طريقة البناء والتشغيل

1. افتح المجلد في Android Studio (Hedgehog أو أحدث).
2. دع Gradle يزامن المكتبات تلقائياً (يحتاج اتصال إنترنت أول مرة فقط).
3. شغّل التطبيق على جهاز أو محاكي (`minSdk 24` أي أندرويد 7 فما فوق).

## رفعه على GitHub

```bash

git add .

git branch -M main
git remote add origin <رابط-المستودع-الخاص-بك>

```
أضف ملف `.gitignore` القياسي لمشاريع أندرويد (مجلدات `build/`, `.gradle/`, `local.properties`).
